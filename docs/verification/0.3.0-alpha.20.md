## Limits

The new continuation fence is a frontend lifetime/project check, not a new atomic
backend operation. Already-dispatched requests can complete after navigation.
Problematic receipts are dismissible only within the latest-three in-memory notice
bound; no durable queue or delivery after app exit is promised. No mutation replay
or retry control was added. Actual native file import, large-receipt geometry,
screen-reader output, Windows lifecycle, current external CI and publication were
not run. The prior AX-associated Linux freeze and denied review-modal route remain
separate, unresolved limits; neither was retried or declared repaired.
