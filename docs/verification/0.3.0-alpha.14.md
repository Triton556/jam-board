# 0.3.0-alpha.14 verification — 2026-10-21

Local development candidate, not an external release. This is the bounded
asset/reference/settings recovery batch plus the independent alpha13 Welcome-load
corrections. No backend or database change; the separately reviewed bootstrap-cursor
patch remains outside this version.

## Reproduction and scope

Independent alpha12 tests reproduced stale asset/reference completion closing newer
drafts, duplicate frame creation, a failed asset source appearing empty, and an old
name save erasing newer typing. Seven owner probes on immutable alpha13 extended
this to reference editing/linking, the existing-reference picker, and start/end,
timezone and milestone fields. Original probes and results are preserved under
ignored `.dev-data/audit/` and `/tmp/alpha13-adjacent-audit.log`.

Independent alpha13 review also established both an empty slow-Welcome interval and
an unrecoverable cached chunk rejection. Those are corrected here; alpha13's original
happy-path onboarding test was not full slow/failing-chunk acceptance.

The dialog fence captures values, the operation callback and project identity,
refuses duplicate dispatch synchronously, locks pending dismissal and shows focused
status. Known errors retain drafts and restore useful focus. Ordinary dismissal and
navigation return after settlement. Project/target change or unmount invalidates
late UI completion, including A→B→A; it does not roll back a submitted transaction.
Asset-link reads have explicit loading/error/retry/empty/filter-empty states.

Settings retain newer edits by revision rather than a key-based remount or value-only
comparison. A newer blur during an older save does not queue another request: the
field stays visibly Unsaved with an explicit Save action. Background read failures
retain the same input/draft. Template confirmation keeps pending/error focus and
returns focus after success. No new backend CAS protects these metadata writes.

File-picker/drop/batch media import and canvas movement/history are not claimed to
have gained transactional cancellation or comprehensive stale-write fencing. Those
paths are outside this individual-dialog correctness batch.

## Limits

No native GUI, current browser runtime, Windows installation or external CI pass is
claimed for this version. The native alpha10 screenshots and unresolved Linux AX
observation retain their original attribution; no denied interaction was repeated.
Controlled DOM chunk tests verify visible feedback, navigation and explicit reload
invocation, not a real browser download retry. Existing performance/frame budgets
remain unchanged; this is not a new performance measurement or accessibility certification.
