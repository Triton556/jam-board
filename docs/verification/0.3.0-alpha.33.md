# 0.3.0-alpha.33 — hidden interaction ownership and recovery

## Behavior repaired

Independent actual-user DOM probes on alpha31 established task-menu Escape closing
the outer drawer, duplicate pending archive requests, pending teammate dismissal,
late edge completion closing a newer draft, and cold command loading with no
cancellable feedback. Rejected palette chunks escaped to an ancestor boundary.
An additional probe found underlying Ctrl/Cmd+S could save a dirty task while its
archive confirmation was pending. These were reproduced defects, not inferred
from test counts or a build.

- **H-D04 / F07 / F08:** first Escape closes task actions and focuses the opener.
  Archive and explicit Unarchive use captured single-flight intent, visible busy
  state and a temporary pending dismissal lock. Parent task Save is blocked while
  that confirmation is open. Restoration does not Start or grant permission.
- **H-M01 / H-R06:** teammate and edge editors retain copyable inputs and local
  errors. Project/entity/lifetime fences prevent a late result closing a new
  editor or triggering a follow-up read in another project. A confirmed write
  followed by failed refresh is reported separately from an unconfirmed write.
- **H-G01 / F11:** cold Search and commands has a cancellable loading dialog;
  dismissing intent prevents late opening. Chunk rejection stays local with Close
  and an explicit Reload app warning, not automatic reload or a fake retry of a
  cached rejected lazy import.

The existing project-write hook, native API, database schema, MCP contracts and
permission checks are unchanged. Pending guards are not idempotency or rollback.
After a dispatched error, no automatic replay is offered. A scheduled project
change that refuses the operation **before dispatch** instead shows the precise
not-sent error, without a contradictory unconfirmed-outcome paragraph.

## Remaining acceptance boundaries

Actual-user DOM/router tests exercise behavior with modeled transport. They do not
establish native menu geometry, Windows GUI behavior, installed upgrade behavior
or a real network failure. Alpha29's native read-only hierarchy observations and
tool-side text-entry failure remain separate. Final combined native inspection
must include nested menu/confirm/loading layouts, visible focus and light/dark/narrow
spacing; unavailable native input paths remain NOT RUN. The new source is not a
claim that every reference details menu or hidden interaction is fully audited.
