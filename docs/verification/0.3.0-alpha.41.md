## Changed behavior

- Board-owned `integrations/agent-skill/jam-board` is the source for both optional
  project skill install and `jam://guide` / `jam://guide/operations` MCP resources.
  No external playbook or universal brain dependency. Existing 44 tools unchanged.
- App installer copies bundled content for Codex/Claude. Preview is read-only;
  confirmed install checks exact ownership, modified files, symlinks and concurrent
  changes; upgrades preserve backups outside discovery folders. A matching private
  app-data record prevents a rewritten target receipt from silently adopting edits.
- Neutral connection prompt checks existing MCP, exact project, guide and folder;
  missing configuration/restart is an explicit handoff, not a false connection.
  No token, automatic role appointment, planning or execution grant is copied.
- Project folder hint is separately stored per project, with exact-project guard
  checked inside the write transaction. It does not change board identity.
