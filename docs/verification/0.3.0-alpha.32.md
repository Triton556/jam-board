# 0.3.0-alpha.32 — empty-column readability and reference frame appearance

## Bounded intent

People should read an empty column at a glance and recognize a reference frame as
one grouping container, without a heavy doubled outline or competing overview
label. This checkpoint changes only UI presentation/copy and related tests/maps.
No database, MCP, permission, assignment, persisted reference or mutation contract
changes. Human-first29, canvas30 and coordination31 remain individually attributed.

## What changed and what remains intact

- H-B01 / AS02 / VS02: genuine empty columns say **No tasks yet**; filters hiding
  existing work say **No matching tasks**. Empty text is 14px/600 primary ink;
  concise subtitles are 14px/500 secondary ink. Actual In progress WIP remains.
  Scope controls retain Ready versus Start versus claim consequences. Quick create,
  keyboard card activation, pointer movement and all data handlers are unchanged.
- H-R02 / RF02 / VS03: one rounded live SVG frame boundary, quiet theme-aware tint,
  paper title/grip and consistent controls. Selected/focus state remains explicit;
  interiors remain pointer-transparent and child/canvas gestures keep their paths.
  The header retains minimum .75 screen scale and broad grip. Its minimum width
  can extend beyond a narrow low-zoom frame; actual overlap is a native check.
- The overview stops drawing a second frame boundary/title. Cards/edges still
  use the previous raster rendering and underlying live model. Existing agent
  result cards, note contents, world coordinates, inline-draft safeguards and
  image-resolution selection are unchanged.

The [agent map](../agents/README.md) and stable acceptance rows are updated. Frame
hierarchy rationale uses [Figma's container model](https://help.figma.com/hc/en-us/articles/360041539473-Frames-in-Figma-Design)
and [Atlassian's boundary/state distinction](https://atlassian.design/foundations/border),
not their appearance as a substitute for inspecting this application.

## Actual versus pending visual evidence

Historical native captures motivated the change; they are not alpha32 screenshots.
Static sRGB token contrast calculations for empty/subtitle text are 13.31/5.37 in
light and 14.44/7.49 in dark. They exclude grain/compositing and are not rendered
pixel measurements or an accessibility certification.

Combined exact-package acceptance still needs undimmed Board in both themes at
narrow width/long title, frame selected/unselected grouping and title/control fit,
39/40/75/100% plus fractional/high zoom, child/grip/interior gestures, collapse and
resize. Whole-board/text blur and representative 500-reference responsiveness remain
unproven; image source tests do not establish them. Native text-entry capability
limits from alpha29 remain explicit. Hosted browser scenarios are pending.
