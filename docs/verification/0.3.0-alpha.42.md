# 0.3.0-alpha.42 — brain dock, voice input and canvas linking

Feature base: `9138d828c7e90e6118c85e2e7b31732a81b96d66` on
`feature/brain-dock`. Release metadata follows on the same branch. The owner
authorized commit and publication; workflow results are reported separately.

## Changed behavior

- Project-pinned Brain dock supports ACP chat, terminal sessions and built-in
  API chat, connection/auth recovery, attachments and staged board context.
  Refine/Continue/Ask brain stages editable drafts; it does not Send or grant Start.
- Local voice input uses an on-demand whisper.cpp sidecar, resumable verified
  downloads, CPU/CUDA selection, warm-up and idle unloading.
- Canvas frame/entity links, Keep / Not this feedback, note-to-task creation,
  grouped gestures and 52 MCP tools preserve project isolation and human intent.
- Interaction-walk fixes cover focus, keyboard menus, pending/retry feedback,
  retained drafts, hit targets, lazy recovery, text sizing and themed scrollbars.

- Native Tauri/WebView2 was **not exercised with real agents**. Claude Code was
  not signed in on the test machine; codex-acp was not probed; live API keys were
  not used. Russian speech was not tested. Real microphone/AudioWorklet,
  packaged voice integration, installer upgrade/data preservation and exhaustive
  native usability remain unverified. No live user board data was used for tests.
- Dock transcripts remain in memory, without app-restart session resume.
  Builds, hashes and process tests do not establish whole-application usability.

Local `test-visuals/` evidence is ignored by Git and is not bundled with the release.
