# 0.3.0-alpha.30 — References editing and image source selection

## Behavior and scope

Based on corrected human-first alpha29 `fcf5e4f`. The new local inline note has
Title/Note, explicit Save and a clearly stated local/not-yet-saved state. It is
unframed at captured world coordinates; existing persisted notes and agent results
are unchanged. Empty input/cancel sends no write. Pending creation locks repeated
sends and dismissal. Any dispatched error is conservatively **unconfirmed**; text
remains copyable, read-only Refresh is available, and another create is disabled.
Discard removes local text only, not an already persisted record. No rollback,
idempotency, automatic retry or filesystem copying is promised.

Dirty navigation uses the existing confirmation contract; pending navigation is
blocked. Confirmation receives focus and returns it on Keep editing. The initial
paper fits measured canvas/tool bounds with readable at-most-100% zoom and internal
scrolling; its saved coordinates remain explicit. Resize after opening and real
small-window geometry require browser/native checks, not pure coordinate tests.

A frame alone now counts as content. Its header/grip is visibly reachable at low
zoom; frame interior remains pointer-transparent. Existing note content, links,
frames and undo behavior are not migrated. Modal forms reuse the existing spacing.

Image source choice uses the untransformed image content box, contain-fit axes,
canvas zoom and live device pixel ratio. A thumbnail must cover both painted axes;
otherwise the original is displayed. URL/lifetime changes suppress old decode
results; thumbnail failures keep the original and an original-image failure exposes
Image unavailable / Retry image. Thumbnail generation still decodes the original,
so no initial-decode saving is claimed. Permanent compositing hints and bitmap
overview are unchanged: whole-board/text blur is **not declared solved**.
