## Remaining limits

The new native human Release command uses exact task-revision CAS. MCP report and
release calls still lack a per-claim generation token: after release and later
reclaim by the same agent identity, an old payload can be indistinguishable from
current work. A dedicated generation/precondition design is the next safety slice;
this version does not claim stale-worker fencing or process cancellation.

No actual external worker process was launched or stopped. No Windows installed
upgrade/uninstall was exercised. Browser E2E execution is not claimed; the private
mock preview remains owner-authenticated and unavailable to the signed-out test
browser. Native QA uses the normal sandbox and isolated app data, not weakened
browser privacy or security settings.
