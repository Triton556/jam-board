## Changed behavior

- Board MCP discovery and first requests bind project and agent identity once,
  including clients that discover before initializing. Project isolation remains.
- CLI/ACP launches use session-specific board server names, environment-based
  credential delivery and stale-configuration warnings without rewriting user
  files. Launch progress and retained redacted logs expose recovery information.
- Global agent configuration supports Ask every time / Always / Never and a
  per-launch choice. Unsupported exclusion is disclosed; a prompt, Ready state,
  answer or heartbeat still does not launch work or grant execution permission.
- Terminal launch waits for fitted dimensions and printable output or a bounded
  timeout. OSC titles feed the session picker. History has Chat/Terminal views,
  provider/model details, supported native resume, rename and Delete/Undo while
  retaining original CLI transcripts.
- Session/access menus, usage-limit reset information, disabled reasons, pending
  states, keyboard focus and reduced-motion behavior receive scoped UX repairs.

## Performance and remaining limitations

- No live providers, actual Claude/Codex/ACP agents, provider prompts or real
  credential-store end-to-end acceptance. Owner-only steps are listed in
  `test-visuals/round7/owner-live-checks.md`; creating the draft does not execute them.
- B4 (stuck left-edge fragments) and B5 (scrambled Cyrillic corrected by selection)
  remain **unconfirmed**. Fixture improvements and absence of a reproduced symptom
  cannot establish that the original owner reports are fixed.
- Linux is covered **only via hosted CI**. Local cross-target diagnostics stop at
  missing `x86_64-linux-gnu-gcc`; Windows CI cannot substitute for Ubuntu results.
- Manual table stress case B, `scoped-stress-2000`, fails its long-frame fraction:
  **0.42063492063492064 > 0.15** (repeat **0.42857142857142855**). Eleven other
  benchmark cases passed. Table/perf source is unchanged in Round 7 and there is
  no baseline for attribution; do not call the failure a proven regression or a
  pass. The hardware benchmark is not a normal CI gate.
- Canvas **<=5 long frames** target remains unmet. Alpha.43's measured final
  medians were 10 (132 items) and 8 (500); Round 7 does not provide a new canvas
  performance acceptance or transfer those measurements to this new package.
- Native evidence uses isolated development WebView/PTY fixtures and limited
  settings persistence, preceding Q1. It does not establish exact-alpha.44
  packaged focus/rendering behavior, install/upgrade/uninstall/data migration,
  physical mouse input, microphone/cloud transcription or human usability.
- Build/asset checks establish engineering integrity and artifact identity only.
  The owner will install and test the draft. Existing board data, independent MCP
  connection, human drafts and execution grants are preserved.
