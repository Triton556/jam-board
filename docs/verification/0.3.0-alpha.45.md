## Changed behavior

- Starting/running project terminals appear in History with Running and focus
  their existing tab; only ended shells without user transcripts are excluded.
  History load/startup recovery relinks alpha.44 records without rewriting native
  transcripts. Claude folder/hash/exact-UUID fallback and Codex cwd normalization
  repair discovery; explicit Resume still creates a fresh dock session.
- Chat separates adapter preparation from initialize: package launchers receive
  180 seconds until first protocol traffic, then 60 seconds for readiness; other
  executables retain 60 seconds. Timeout copy names the connection and offers
  explicit Retry, Show logs and collapsed technical Details.
- Context percentage, exact-token/optional cost tooltip and Session status expose
  reported connection/model/access, board MCP evidence/name, global configuration,
  context/cost and session start time. Cost is not remaining plan allowance.
- /status stays local. Exact advertised /usage sends one text block to the adapter
  without consuming staged context/files or the first normal-message preamble;
  otherwise it opens local usage status. Unknown commands retain the draft with
  guidance. The slash menu remains advertised-only; adapter Markdown is a reply.
- Codex Plan usage projects recorded primary/secondary limits from the newest
  rollout for the exact native session. Missing data stays unavailable; status
  queries refresh snapshots, not live account quotas.

## Performance and remaining limitations

- No live providers, Claude/Codex/ACP agents, provider prompts, real sign-in or
  credential-store round trips. Worker owner re-check lists remain the live QA
  handoff; this release task never runs them.
- R8-B1's cold-adapter root cause remains a **hypothesis**, mitigated by the longer
  preparation budget and clear recovery, not confirmed by a real cold launch.
- There is no stable Claude plan-limit API integrated. The installed adapter's
  advertised /usage owns the command/control operation and Markdown output; Jam
  Board does not parse the experimental SDK usage response. Source inspection
  does not establish which adapter version caused the owner's alpha.44 failure.
- Linux is covered **via hosted CI only**. Local cross-target checks stop at
  missing `x86_64-linux-gnu-gcc`; Windows/source review cannot substitute.
- Alpha.44 manual perf case B (`scoped-stress-2000`) remains open:
  long-frame fraction 0.42063492063492064 > 0.15, repeat 0.42857142857142855.
  Table source is unchanged and no attribution baseline exists. It was not rerun;
  normal CI excludes this manual hardware benchmark.
- The canvas <=5 long-frame target and original B4/B5 terminal corruption remain
  unconfirmed/unmet as documented in alpha.44; no new performance or corruption
  acceptance is inferred from this release.
- No exact-alpha.45 packaged-native UI, installation/upgrade/uninstall, migration,
  startup interruption/descendant cleanup or human usability acceptance. Workers'
  mock screenshots do not establish native pixels, DPI or physical input behavior.
- Build/asset checks establish engineering integrity and artifact identity only.
  Human drafts, project identity and execution grants retain their semantics.
