## Changed behavior

- Boards can use their own folder: jamboard.json manifest, portable board.json
  snapshot and local .state/. Create/open, Locate and registry-only removal retain
  old app-data projects. Moving is optional, with preview, progress, resume and
  rollback; connected agents block a move.
- Automatic backups keep 10 recent and 7 daily copies plus pinned safety backups.
  Save now publishes a snapshot. External snapshot changes or missing .state
  trigger explicit compare/keep/restore recovery.
- Task Files support owned copies, project links and URLs, task-specific edit,
  reference and result roles, Open/Reveal, reorder and association-only unlink.
  Missing/unreadable states are explicit. Assets filter by storage and task usage.
- A shared editor supports drawer and large modal (?taskView=modal), preserving
  drafts and pending work. Pointer opening suppresses the container focus ring;
  keyboard focus remains visible. Hidden exit keeps modal ownership until the
  route owner unmounts.
- Canonical board locators work independently of cwd/worktrees, with project cwd,
  pinned source/history and move leases. Five new MCP tools register/link/set role/
  unlink/resolve files; get_task exposes files and the bundled guide explains them.
- Narrow top-bar actions use a labeled More menu. Round 10 composer More uses
  visible option names/descriptions, switches for boolean choices and an icon
  chip with an active dot.
- Contracts include PF01–PF11, TF01–TF08, TV01–TV03, AF01–AF06, FQ01–FQ46,
  H-D01 deferred close, BD06/BC07 and AG15. Project isolation, grants and drafts
  retain their existing boundaries.

## Performance and remaining limitations

- No live providers/agents, actual Claude/Codex/ACP/Blender, adapter downloads or
  provider prompts. Automated transports use disposable scripted fixtures.
- Native folder pickers, OS Open/Reveal, DPI, exact-package UI, installation,
  upgrade/uninstall, native crash/relaunch and human usability are not checked.
  The built app is not launched. Existing data and independent MCP are preserved.
- Linux is covered via GitHub CI only. Local ci-local used Node 26 by explicit
  override; GitHub CI checks Node 22 parity on Windows and Ubuntu.
- Perf case B remains open and is not rerun. Normal CI does not establish the
  hardware-dependent performance targets or resolve earlier corruption reports.
- Files phase 2 previews and phase 3 git badges are not included.
- npm ci reports one existing high-severity advisory; dependency remediation is
  outside this release. Build/hash success establishes integrity, not usability.
