## Regression scope

Two probes against exact alpha7 reproduced the defects before implementation:
an open comparison silently replaced its saved version after a background edit,
and a failed resolution had no error inside the still-open modal. The new tests
first failed for those specific reasons, then passed with the corrected behavior.

Eight focused probes cover:

- Frozen starting/saved/local snapshots; background changes block resolution.
- Explicit reread, failed reread recovery, retained draft and heading focus.
- Saving only edited fields with the exact inspected revision; unrelated fields
  survive and success leaves a receipt and stable task-drawer focus.
- Pending double-click, Escape, backdrop and hidden Ctrl+S refusal; failed save
  stays inside the modal and can be intentionally retried.
- Closing/reopening without saving or losing the local draft.
- Friendly structured brief comparison and honest whole-list replacement, while
  unedited remote brief properties remain preserved by the existing merge logic.
- A write race returning conflict without fresh-token refill or automatic replay.
- Initial conflict-read failure with a read-only retry, not a repeated stale write.

The task patch algorithm is unchanged: it merges edited top-level/brief properties,
not individual Changes/test-list entries. The comparison explicitly states this.
No SQLite migration, MCP request/schema change, execution grant, actor identity,
external process or separate playbook repository is modified.
