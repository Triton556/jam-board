planning mutation despite its recent file timestamp. Rebuilding the actual sidecar
resolved the mismatch; no version guard was relaxed. The supported installed
scenario requires an explicit fresh-disposable flag, exact parent/path/version/

and native Welcome-form sequence are **NOT_RUN** here. Historical scripts remain
preserved evidence with an early incompatible-contract guard, not current examples.
