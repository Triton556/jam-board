# 0.3.0-alpha.16 verification — 2026-10-21

This is a bounded content/readability batch after immutable alpha15: semantic
Markdown reading/editing, conservative generic-asset classification/copy, and an
explicit whole-project rough-capture inventory instruction. No backend, schema,
dependency, tool, opener policy or execution permission is changed.

## Reproduction and behavior

The independent alpha13 Markdown audit used the actual lazy renderer, not a text
stub. Pointer and Enter on a reference invoked the mocked URL opener and also
entered editing; headings/lists/links were inside the edit button. Normal blur,
Escape, Ctrl/Meta+S and Enter did not reproduce duplicate saves or lost drafts.
The original audit is preserved in ignored `.dev-data/audit/independent-alpha13-markdown.test.tsx`.
The owner's desired-behavior tests were red before the repair; log:
`/tmp/alpha15-markdown-expected-red.log`.

The field now has ordinary content and a separate visible Edit action. Links remain
semantic when editing is disabled; empty disabled content says Not provided.
Keyboard save/cancel restores Edit focus when available, while ordinary blur leaves
focus on the chosen next control. No read action itself submits or edits a brief.
Actual native text selection, clipboard behavior and screen-reader traversal are
not inferred from DOM tests. The earlier disabled nested-link simulations differed
by event dispatch; no claim of a proven old native link blocker is made.

Generic assets default to other, and JSON does not infer a game level. Explicit
manual kinds (including deliberately selecting the current default) survive later
file suggestions; existing JSON assets classified as level retain their stored kind
when edited. Auto suggestions still follow files until a human explicitly chooses.
A Kind-option test additionally exposed a wrapped-label accessibility-name defect;
the label now targets only the trigger, and the same option-name assertions pass.
Original red: `/tmp/alpha16-asset-kind-label-red.log`.

The project handoff now names full non-archived task pagination, including unassigned
Backlog, because get_board is a summary. Epic/Story/Task handoffs do not broaden to
that project inventory. This is source-based guidance, not a measured model result,
archive scan or automatic authorization.
