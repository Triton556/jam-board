# 0.3.0-alpha.35 — action feedback and native-found overlay corrections

## Scope and behavior

Questions and Journal retain cached content during failed reads; an unsaved answer
keeps its exact editor node, draft and focus. Table retains cached rows. Explicit
Refresh/check actions on those views, Assets, References and project notifications
are locally single-flight and report Checking, actual read outcome and a checked-at
timestamp. A resolved TanStack error is not a successful check. Receipt ownership
is fenced by resource/filter, project generation and lifetime; background refreshes
never announce a false successful user action. Bell latest/older request ownership
and bounded pagination are retained.

PlanningInput autosave reports submitted/pending, acknowledged success, newer
unsaved text and uncertainty without silently replacing a draft. A missing or
changed project refuses dispatch. Its established later human refocus/blur retry
contract is unchanged. A confirmed save after leaving an entity reconciles only
its captured existing draft baseline, under uninterrupted project and cache
ownership: newer unsaved text remains; unchanged confirmed text returns clean.
No stale view receipt, refetch or focus is applied. This is not idempotency or proof
that an error rolled back.

Native alpha34 observed a stationary open presence tooltip lagging its updated
label. The candidate uses the existing live React tooltip without changing
heartbeat cadence, task state or permissions. Native34 also found a short frame
title truncated at 49%, a reference action menu that ignored Escape/outside clicks,
and a Link-reference Select clipped to search plus a group-heading sliver.

Frame headers now prioritize titles above controls when narrow, and explicit Fit/F
includes header/tool extents. Saved camera on ordinary entry remains untouched.
Reference menu dismissal preserves the clicked target and returns child-dialog
focus to the visible summary. Compact selects use feature-detected manual Popover
presentation, staying in their modal DOM ownership, with in-flow recovery when the
API is missing or throws. The independently passing native34 lower-edge Task Status
case must be rechecked because this shared primitive changed.

No schema/tool, execution grant, Start/claim/review, process launch, paid API or
session-streaming feature is added. The embedded CLI/API concept remains separate.
