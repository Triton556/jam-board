## Explicit limits

Claim/context validators are freshness checks, not credentials, process stopping,
time leases or external filesystem fencing. Append-only comments/questions/
references, informational presence ordering and general Epic/Story edit CAS are
outside this slice. An authorized identity deliberately reading a fresh context is
not identified as a different OS process. No actual worker process or real server
work was launched. Legacy databases/snapshots preserve data, never import execution
authority; older MCP writers must refresh schemas, reread and reconcile before retry.
