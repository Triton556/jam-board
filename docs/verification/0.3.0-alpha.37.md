# Alpha37: reference keyboard ownership

## Observed baseline

Hosted [run 39779989398](https://github.com/Triton556/jam-board/actions/runs/39779989398)
tested published `f73a997fab2025fca035df361d9bb3e2117668c6` (source alpha35
`86889c1c54cb6d7fc71e04cc10131f06dc38717c`). Windows passed all checks and its
debug desktop build. Linux passed its Rust, Node, type and DOM gates, then **86 of
89** functional browser scenarios. The three failures are retained, not relabeled:

- Two frame cases invoked the test bridge while the actual page still displayed
  **Loading References**. They now await the visible canvas/frame and bridge;
  this is test readiness, not a hidden production retry or a longer timeout.
- The reference menu opened with Enter and closed with Escape, but Space did not
  reopen it. The installed ReactFlow document key handler does not classify
  `SUMMARY` as interactive and prevented the browser default. An independent
  actual-hook probe and the owner's red regression confirmed that mechanism.

## Bounded change

Only Space keydown on the reference Actions summary stops propagation. It does
**not** call `preventDefault` or synthesize a click. Menu buttons, other keys and
the canvas's own Space gesture retain their existing ownership. No data writes,
execution permissions, tools, schema, dependency or native backend logic changed.
The separately requested direct-sticker creation design is not part of alpha37.

## Evidence and limits

The owner regression uses the installed ReactFlow `useKeyPress` hook: summary
Space remains uncancelled and does not enable panning; Space outside the control
still enables and releases canvas panning. It failed before the fix. Happy DOM
does not implement native summary keyboard activation, so the unchanged hosted
**Enter → Escape → Space** scenario must still run before browser acceptance.

Local final gates passed: **753 DOM tests in 101 files** (two workers), **26 Node
tests**, app/E2E TypeScript, lint (283 files), production frontend build, version
consistency, canonical-map uniqueness and whitespace checks. Rust formatting and
locked offline metadata passed; Rust/schema/generated-binding source is identical
to alpha36 apart from version metadata. This is **not** a fresh Rust test run.
The targeted regression's red result and the initial lint rejection of a handler
directly on `summary` were retained; the final handler uses the existing details
capture listener with an exact summary-target guard, without adding a false role.

Independent pinned review, hosted rerun and exact changed-control native
acceptance are **NOT RUN** at this freeze.
Alpha36's separate native layout/packaged stdio evidence remains attributable to
its immutable source `5721f7e63ba67ec6e1adedf2c8017f6eedf4eaab`, not alpha37.
