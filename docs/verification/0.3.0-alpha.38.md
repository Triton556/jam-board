# Alpha38: direct note paper (hosted test-contract repair pending)

## Scope

The user rejected the previous canvas form. This candidate places actual editable
paper, focuses its body, makes the heading optional and replaces explicit creation
Save with truthful serial autosave. Existing note-kind cards reopen in the same
editor; media/result content is not rewritten. See the
[direct-note contract](../agents/direct-sticky-notes.md).

Native-only optional empty-heading creation preserves no-heading across reload.
Shared create validation also broadens legacy/MCP acceptance to heading-only
notes; old successful calls/default headings stay compatible, but behavior is not
identical. New blank-both creation fails; an existing deliberately cleared note
remains a valid export/import record. No database migration or MCP schema change.

Human updates compare exact inspected heading and body inside the Store write
transaction. This is equality-based conflict protection, not historical revision
tracking, a global lock on agents, automatic merging or idempotent creation.
