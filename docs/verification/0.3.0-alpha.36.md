# 0.3.0-alpha.36 — reference overlay spacing

## Observed problem and narrow correction

Exact alpha35 native Refresh produced a readable receipt but its expanded toolbar
background overlapped the filter-panel background by approximately 137 × 13 px at
1180 × 812. No blocked control was observed. The fixed filter/read-notice top
offsets did not follow a wrapping toolbar. This is an observed spacing defect,
not a claim that the reference read failed.

Alpha36 places tools, right-aligned wrapping filters and conditional read notices
in a single normal-flow overlay with an 8 px gap. The overlay itself is
pointer-transparent; only visible controls/notices accept pointer input. Empty
notices take no space. Fit and initial inline-note placement use the same fresh
whole-overlay bounds, including error feedback. No observer loop, background
camera reset, canvas geometry write or changed mutation contract is added.

The existing note-placement policy only fits the initial draft into the available
space. Extreme content that consumes the entire viewport and resizing an already
open note remain separate limits; this change does not claim an unlimited layout.
